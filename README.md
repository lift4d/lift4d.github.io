# Lift4D — project page

Static project website for **Lift4D: Harmonizing Single-View 3D Estimation for
4D Reconstruction In-the-Wild**.

## What's here

- `index.html` — the full project page (abstract, animated methodology figure,
  comparisons, interactive-viewer section).
- `viewer4d.html` — the embedded WebGL 4D viewer.
- `static/` — page assets: CSS, the WebGL viewer (`js/gs4d_player.js`), scene
  thumbnails, the methodology animation data (`methodology/rhino_cloud.json` +
  real rhino frame crops), and the teaser / comparison / inset videos.

## Viewing

Served as a plain static site (e.g. GitHub Pages) — `index.html` is the entry
point. The interactive 4D viewer runs entirely client-side in WebGL.
